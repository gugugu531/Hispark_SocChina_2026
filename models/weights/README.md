# 模型生成物目录

本目录用于本地生成的模型与转换产物，除本说明外均被 Git 忽略。

常见内容：

| 后缀 | 含义 |
| --- | --- |
| `.onnx` | FP32 或 FP16 静态 ONNX |
| `.om` | 面向 `OPTG` 的 FP16 OM |
| `.om.json` | OM 算子与 engine 检查结果 |
| `.fusion_result.json` | ATC 融合结果 |
| `.bin` | ISP CLUT 等板端输入数据 |

命名使用 `<任务>_<宽>x<高>_<变体>_<精度>`。不要把此目录当作唯一证据来源：可复现命令、
测量条件和结论必须写入对应 Markdown 报告，重要汇总数据放入 `artifacts/`。

清理本目录不会删除源码，但会删除不可由 Git 恢复的本地模型产物。清理前先确认所需文件能由仓库脚本
重新生成。
