# 画质验收

## 2026-06-20 当前场景重复性验收

目标：

- 检查强制 param-net RGB CLUT 在当前高动态范围场景中的安全性。
- 检查生产高光门控触发后的规则 Gamma 回退路径。
- 建立可重复的 NV21 批量指标与接触表工具。

数据与路径：

- 采集：7 组三态 param-net 序列，共 21 张 `1024x600 NV21`。
- Gamma 公平 A/B：等待 30 帧 AE 收敛后抓 BYPASS，只施加一次 BIDIR，等待 6 帧后抓 AFTER；
  强度分别测试 `0.7` 和 `0.25`，每档 7 组。
- 分析工具：`python -m models.tools.quality_acceptance`
- 生成物：`artifacts/quality-acceptance/current-scene/analysis/`
  - `summary.json`
  - `frame_metrics.csv` / `pair_metrics.csv`
  - `contact_sheet.png`
  - `gamma_frame_metrics.csv` / `gamma_pair_metrics.csv`
  - `gamma_contact_sheet.png`

验收门：

| 指标 | 门限 |
| --- | ---: |
| 高光裁剪增量 | ≤1 个百分点 |
| 黑场裁剪增量 | ≤1 个百分点 |
| 细节梯度保留 | ≥80% |
| 平均 RGB 通道差相对基线增量 | ≤5 |
| 七组输出亮度标准差 | ≤5 |
| 最低样本量 | ≥20 帧 |
| 最终场景覆盖 | ≥5 类代表性场景 |

这里的指标是无参考工程安全门，不等于主观画质金标准。

### 强制 param-net RGB CLUT

结果：

- OFF 高光裁剪均值：`3.95%`。
- ON-after 高光裁剪均值：`6.90%`，增加 `2.96` 个百分点，失败。
- 细节梯度保留：`64.4%`，失败。
- ON-before → ON-after 的 Y MAE：`15.76`，反馈稳定性失败。
- 21 帧最低样本量通过，但只有 1 个场景。

解读：

- 当前 RGB LUT 在该场景会明显压暗全局，同时未保护已经裁剪的屏幕高光。
- 生产路径必须保留 `clip_high_pct > 3%` 时旁路 NN CLUT 的门控。
- 当前权重不能作为“所有场景无条件启用”的最终模型。

### Gamma 0.25 公平 A/B

结果：

| 指标 | BYPASS | BIDIR 0.25 | 变化 |
| --- | ---: | ---: | ---: |
| 平均 Y | 93.80 | 132.75 | +38.95 |
| `Y>=250` | 1.70% | 2.33% | +0.63 pp |
| `Y<=5` | 0.0014% | 0% | -0.0014 pp |
| 梯度代理 | 7.83 | 8.11 | 1.036× |
| RGB 均值通道差 | 18.20 | 22.02 | +3.82 |
| 七组输出 Y 标准差 | — | 0.12 | 稳定 |

所有当前场景 Gamma 安全门通过。接触表显示输出是温和提亮，未出现强制 RGB CLUT 的明显整体压暗
和额外高光爆白。

决策：

- 生产默认 `TONE_STRENGTH` 从 `0.7` 降为 `0.25`。
- 当前场景下，生产“高光门控 → Gamma 0.25 回退”通过。
- 强制 NN CLUT 不通过，继续受高光门控和降级路径约束。

## 最终验收状态

**未完成。**

本轮满足了最低帧数，但 21 张 param-net 帧和 Gamma A/B 均来自同一固定场景，不能代表完整产品画质。
最终验收至少还需覆盖：

1. 极低光静态场景；
2. 强逆光/窗户/灯管；
3. 正常曝光日常场景；
4. 人脸与肤色；
5. 运动物体和手持晃动；
6. 彩色物体/色卡；
7. WDR 2to1 下的同类场景。

每类建议至少 3–5 组公平 A/B，并补人工评分：暗部可见性、高光细节、肤色、伪色、banding、噪声和
运动稳定性。达到至少 20–50 张独立场景帧后，才能把最终画质验收标记为通过。
